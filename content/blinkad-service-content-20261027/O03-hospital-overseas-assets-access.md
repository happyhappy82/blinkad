# 병원 다국어 홈페이지, 해외에서 영상·지도까지 열어보세요

병원 다국어 홈페이지가 국내에서 잘 열리더라도, 목표 국가에서 영상과 지도까지 이용할 수 있는지는 따로 확인하는 게 좋습니다. 본문은 열리는데 외부 서비스로 연결한 안내가 보이지 않을 수도 있거든요. 해외 접속 검수에서는 어느 국가의 어떤 환경에서 무엇을 확인했는지와, 보이지 않을 때 대신 읽을 정보를 함께 정리하시면 됩니다.

저희가 권하는 점검은 외부 요소가 어디에서 불러와지는지, 고객에게 필요한 안내가 끝까지 보이는지를 함께 확인하는 것입니다. 이를 기준으로 실제 접속을 시험할 국가와 담당을 정해보시면 됩니다.

## 홈페이지 밖에서 불러오는 요소부터 정리합니다

페이지에는 병원 서버에 있는 본문 외에도 외부 폰트, 동영상, 지도와 같은 요소가 들어갈 수 있습니다. 어느 서비스에서 불러오는지 알면 문제가 생겼을 때 홈페이지 제작 담당과 외부 서비스 중 어디부터 확인할지 정하기 쉽습니다.

예를 들어, 병원 소개 영상과 찾아오는 길 지도를 각각 다른 서비스에서 가져온다면 두 요소를 따로 확인할 수 있어야겠죠. 페이지 전체가 열렸다는 이유만으로 둘 다 이용할 수 있다고 처리하면 검수 범위가 빠질 수 있습니다.

| 확인할 요소 | 접속할 때 살펴볼 내용 | 함께 준비할 대안 |
|---|---|---|
| 외부 폰트 | 글자가 보이고 문장이 읽히는지 | 기본 글꼴로도 읽을 수 있는 화면 |
| 병원·진료 안내 영상 | 재생과 필요한 설명을 확인할 수 있는지 | 핵심 안내의 해당 언어 본문 |
| 외부 지도 | 위치와 길 안내를 사용할 수 있는지 | 주소·건물명·층·교통 안내 |
| 외부 서비스로 연결된 안내 | 실제 도착 화면과 필요한 정보 | 해당 정보의 본문 안내 또는 이용 가능한 다른 경로 |

이 표를 제작 담당자와 공유해 어떤 외부 요소가 있고, 누가 확인할지 적어두시면 됩니다.

## 접속 국가와 브라우저 언어는 다른 조건입니다

국내에서 브라우저 언어를 영어로 바꾸는 시험과 해외 네트워크에서 접속하는 시험은 확인할 수 있는 내용이 다릅니다. 언어를 바꿔 표시 상태를 볼 수는 있어도, 그것만으로 목표 국가의 접속 상태를 확인했다고 말하기는 어렵습니다.

해외 접속을 시험했다면 국가·지역과 사용 기기, 브라우저, 네트워크, 확인 시각을 남겨두세요. 같은 국가 안에서도 접속 환경이 다를 수 있으니 확인한 범위를 구체적으로 적는 게 좋습니다. 아직 실제 접속 시험을 하지 않았다면 시험할 계획과 완료한 결과를 나눠두시면 됩니다.

문제가 보이면 ‘지도 영역이 비어 있음’, ‘영상 재생이 시작되지 않음’처럼 관측한 현상부터 기록해보세요. 화면이 비었다는 사실만으로 국가 차단이나 특정 서비스의 장애를 원인으로 확정할 필요는 없습니다.

개발 담당자는 브라우저의 네트워크 확인 도구 등으로 어떤 요청이 실패했는지 살펴볼 수 있습니다. 이때 국내에서 속도를 느리게 설정한 시험과 실제 해외 접속 결과는 구분해서 받으시면 됩니다. [Chrome 네트워크 요청 확인 안내](https://developer.chrome.com/docs/devtools/network/)
