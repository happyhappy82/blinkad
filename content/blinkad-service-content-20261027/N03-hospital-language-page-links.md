# 병원 다국어 홈페이지, 진료별 언어 연결을 확인하세요

병원 다국어 홈페이지를 검수하실 때는 언어 버튼이 보이는지와 함께, 그 버튼을 누르면 어느 페이지로 가는지도 살펴보시면 좋습니다. 특정 진료를 읽다가 영어를 선택했는데 병원 첫 화면으로 돌아간다면 고객은 같은 안내를 다시 찾아야 하거든요. 같은 진료의 다른 언어 페이지로 이어지는지, 해당 언어의 안내가 없을 때는 무엇을 보여줄지 정해두시면 됩니다.

저희가 권하는 방법은 진료별 주소를 한 표에 놓고 확인하는 것입니다. 진료별 번역 페이지와 언어 버튼의 도착지를 함께 보면, 빠진 안내와 잘못된 연결을 찾기 쉽습니다.

## 언어별 첫 화면보다 진료 페이지에서 출발합니다

첫 화면의 한국어·영어 버튼만 확인하면 진료 페이지의 연결이 빠져 있어도 지나치기 쉽습니다. 고객이 검색이나 공유 링크로 진료 안내에 바로 들어오는 상황도 생각해보세요. 그 페이지에서 언어를 바꿔도 필요한 내용을 이어 읽을 수 있어야 합니다.

Google은 언어별로 서로 다른 URL을 사용하고 사용자가 다른 언어 버전을 선택할 수 있는 링크를 제공하도록 안내합니다. 실제 본문이 어떤 언어인지도 중요합니다. 메뉴가 영어여도 진료 설명이 한국어로만 남아 있다면 고객이 찾던 영문 안내가 준비된 상태로 보기는 어렵겠죠. [Google 다국어 사이트 안내](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)

검수할 때는 진료명, 기준이 되는 한국어 주소, 다른 언어의 실제 주소, 버튼을 눌렀을 때의 도착지를 나란히 적어보시면 됩니다.

| 확인한 상황 | 먼저 볼 내용 | 정할 작업 |
|---|---|---|
| 영문 진료 페이지가 있고 같은 내용으로 이동합니다. | 도착 주소와 실제 본문의 진료명 | 내용과 문의 연결까지 확인 |
| 영문 진료 페이지는 있는데 첫 화면으로 이동합니다. | 진료별 언어 버튼의 연결 주소 | 해당 진료 페이지로 연결 수정 |
| 해당 언어의 진료 안내가 없습니다. | 실제 제작 범위와 현재 제공 가능한 정보 | 미제공 안내와 이동할 곳 결정 |
| 버튼은 영어인데 본문이 한국어입니다. | 번역·게시 상태와 최종 확인 원문 | 제공 언어 표시와 공개 내용 맞추기 |

이 표는 검수할 때 활용할 수 있는 예시입니다. 모든 진료를 모든 언어로 즉시 만들기보다, 이번 제작 범위와 실제 공개 상태를 먼저 맞추시면 됩니다.

## 해당 언어의 진료 페이지가 없을 때도 안내가 필요합니다

언어별 제작 범위가 다르다면 고객이 그 차이를 알 수 있게 해두는 게 좋습니다. 없는 페이지로 보내거나, 영문 첫 화면이 같은 진료의 번역본인 것처럼 연결하면 무엇을 읽고 있는지 혼동할 수 있습니다.

예를 들어, 해당 진료는 아직 영문 안내가 없다는 내용을 보여주고 현재 이용할 수 있는 진료 목록이나 문의 안내로 연결하는 방법을 생각해볼 수 있습니다. 언어 선택지를 표시하는 방법도 함께 정할 수 있겠죠. 어느 방식을 쓰든 고객에게 무엇이 제공되고 있는지가 분명해야 합니다.

이때 안내할 문의 창구가 실제로 그 언어에 응대할 수 있는지도 병원 담당자와 확인하시면 좋습니다. 언어 버튼을 추가하는 작업과 해당 언어의 내용·문의 안내를 준비하는 작업을 함께 봐야 하는 이유입니다.

## 화면의 언어 버튼과 검색용 언어 표시는 따로 확인합니다
