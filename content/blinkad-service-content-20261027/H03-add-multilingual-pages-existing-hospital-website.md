# 병원 다국어 홈페이지, 기존 한국어 사이트에 추가하려면

기존 한국어 홈페이지는 계속 운영하면서 외국어 페이지를 추가하고 싶으신가요? 추가할 수 있을지는 현재 사이트의 제작 방식과 호스팅·도메인 설정, 변경 권한을 먼저 살펴봐야 알 수 있습니다. 이때 **새 페이지를 누가 만들지와 함께, 기존 메뉴를 누가 연결하고 오류가 나면 누가 복구할지도** 정해두셔야 합니다.

처음부터 기술적인 내용을 모두 정리하실 필요는 없습니다. 현재 홈페이지 주소와 제작·운영 담당자의 연락 창구, 추가하고 싶은 언어와 진료 안내 목록부터 준비해 주세요. 이 자료를 놓고 한국어 사이트에서 유지할 부분과 새로 만들 부분을 나눠보면 됩니다.

## 우선 기존 제작사와 수정할 수 있는 범위를 이야기합니다

같은 공식 도메인에 새 언어 페이지를 넣으려면, 현재 사이트에서 그 페이지를 연결할 수 있어야 합니다. 별도 영역에 파일을 올릴 수 있는 사이트도 있지만, 사용 중인 제작 도구나 호스팅에서 허용하는 방법에 맞춰야 하는 사이트도 있거든요.

기존 제작사나 운영 담당자와 아래 내용을 이야기해 보시면 됩니다.

- 현재 홈페이지는 누가 운영하며, 호스팅·도메인 설정은 누가 변경할 수 있나요?
- 새 언어 페이지를 연결할 영역을 추가할 수 있나요?
- PC·모바일의 언어 메뉴는 누가 수정하나요?
- 새 영역을 연결하려면 기존 사이트의 어떤 설정을 바꿔야 하나요?
- 변경 전 상태를 보관하고 문제가 생겼을 때 되돌릴 담당은 누구인가요?

병원 담당자께서 서버 설정 방법까지 직접 알아보실 필요는 없습니다. **어디까지 바꿀 수 있고 누가 작업할지만 먼저 확인하시면 됩니다.** 추가 제작 담당이 필요한 설정을 설명하면, 기존 운영 담당이 적용할 수 있는지와 한국어 사이트에 어떤 영향이 있는지를 확인하는 식으로 협의하면 됩니다.

## 새 언어의 주소를 정할 때 기존 한국어 주소도 함께 봅니다

새 언어 페이지는 기존 한국어 페이지와 주소가 겹치지 않도록 준비해야 합니다. 예를 들어, 영어 영역에 `/en/` 같은 경로를 생각해볼 수 있습니다. 실제로 이 경로를 사용할 수 있는지는 현재 사이트 설정을 보고 판단하게 됩니다.

Google은 언어마다 별도 URL을 사용하는 방식을 권장하고, 하위디렉토리·서브도메인 등 주소 구조별 장단점을 안내하고 있습니다. 어느 구조가 우리 사이트에서 가능한지, 앞으로 누가 어떻게 관리할지를 함께 보고 고르시면 됩니다. 같은 도메인의 하위디렉토리를 쓰는 것만으로 검색에서 더 유리해진다고 단정할 수는 없습니다. [Google 다국어·다지역 사이트 안내](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)

주소 목록을 만드실 때는 ‘유지할 한국어 페이지 → 추가할 언어 페이지 → 메뉴에서 연결할 곳’을 나란히 적어보세요. 메인 화면뿐 아니라 병원 소개·주요 진료·의료진·문의 안내까지 제작할 범위에 맞춰 적으면, 어떤 화면을 만들고 어디로 연결할지 확인하기 쉽습니다.

다만 기존 한국어 주소까지 바꿀 계획이라면 주소 변경 작업은 따로 구분해두는 게 좋습니다. 기존 주소와 새 주소를 연결하고 관련 링크도 바꾸는 등, 사이트 이전에 필요한 확인이 추가되거든요. 새 언어 영역을 만드는 일과 한국어 주소를 바꾸는 일을 나눠서 협의하시면 됩니다. [Google URL 변경이 있는 사이트 이전 안내](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)

## 두 제작사와 병원이 맡을 일을 나눠보겠습니다

페이지를 만드는 업체와 기존 사이트 설정을 바꾸는 업체가 다르면, 한쪽 작업이 끝나도 아직 공개하지 못하는 경우가 생길 수 있습니다. 그래서 아래처럼 맡을 일을 한 표에 정리해두면 좋습니다. 사이트마다 권한과 계약 범위가 다르니, 실제 담당자와 확인 일정은 이 표를 놓고 협의하시면 됩니다.

| 확인할 작업 | 기존 제작사·운영 담당에게 확인할 일 | 추가 제작 담당이 정리할 일 | 병원에서 결정·확인할 일 |
|---|---|---|---|
| 새 영역 연결 | 사용 가능한 경로와 필요한 설정 변경 | 언어별 주소·페이지 목록, 필요한 설정 | 유지할 한국어 영역과 제작 범위 |
| 언어 메뉴 | 기존 PC·모바일 메뉴의 수정 담당 | 새 페이지의 메뉴와 언어별 연결 | 표시할 언어명과 진료별 페이지 연결 |
| 자료·내용 확인 | 기존 자료를 제공할 범위와 방법 | 사용할 원문·이미지·번역문의 목록 | 공식 정보와 사용 가능한 자료, 최종 확인 담당 |
| 공개 | 기존 사이트에 적용할 변경과 반영 일정 | 새 영역 공개와 연결·화면 확인 | 내용 확인 완료 여부와 공개 시점 |
| 오류·복구 | 기존 설정·메뉴를 되돌릴 담당과 방법 | 새 영역과 연결 설정의 복구 범위 | 문제 접수 창구와 중단·복구 결정 담당 |
| 공개 후 수정 | 기존 사이트의 메뉴·호스팅 변경 시 연락 범위 | 변경 내용이 영향을 주는 언어별 페이지 | 변경 자료를 전달할 담당과 운영 계약 범위 |

예를 들어, 추가 제작사가 영어 페이지를 완성했어도 기존 홈페이지의 모바일 메뉴를 수정할 권한이 없다면 메뉴 연결은 다른 담당자가 맡아야 합니다. 이 작업을 누가 언제 해주실지까지 정해져야 공개 일정도 맞출 수 있겠죠.

## 공개 전에는 두 언어의 화면을 오가며 확인합니다

새 언어 페이지가 잘 열리면 다음으로 언어를 바꿔가며 이용해보시면 됩니다. 기존 한국어 페이지에서 새 언어로 이동하고, 다시 한국어로 돌아오는 흐름까지 살펴보는 겁니다.

PC와 모바일에서 언어 메뉴를 눌러보고, 특정 진료 페이지에서 언어를 바꾸면 어느 페이지로 이동하는지 살펴보세요. 해당 언어의 대응 페이지가 없다면 어디로 안내할지도 정해두면 됩니다. Google 역시 [사용자가 언어를 선택할 수 있는 링크](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)를 안내합니다. 언어별 대응 관계를 검색엔진에 알리는 `hreflang` 설정을 쓴다면 실제 페이지 주소와 맞는지는 제작 담당이 확인해야 합니다. [Google 언어별 페이지 버전 안내](https://developers.google.com/search/docs/specialty/international/localized-versions)

유지하기로 한 한국어 메인·주요 진료·문의 화면도 함께 보셔야 합니다. 메뉴와 이미지, 문의 버튼이 이전처럼 작동하는지 변경 전후를 비교해보면 됩니다. 공통 메뉴나 설정을 바꿨다면 그 영향을 받는 화면까지 확인하는 게 좋습니다.

외국어 페이지의 문의 버튼도 직접 눌러보세요. 병원에서 실제로 응대하실 창구로 연결되는지, 해당 언어의 안내와 연락 방법이 맞는지까지 확인하면 됩니다.

## 공개 후에는 정보 수정과 검색 확인이 이어집니다

페이지를 공개한 뒤에는 화면이 잘 열리는지와 검색에 색인됐는지를 나눠서 보시면 됩니다. Google은 검색에 필요한 접근·응답·본문 등의 기술 조건을 안내하고 있는데, 이 조건을 갖춰도 색인은 보장되지 않습니다. 제작 담당과 공개 화면 확인, 검색 접근·색인 확인을 각각 이야기해두시면 좋습니다. [Google 검색 기술 요구사항](https://developers.google.com/search/docs/essentials/technical)

운영 중 의료진·진료시간·문의처가 바뀌면 누구에게 알려주실지도 정해두세요. 두 제작사의 운영 범위가 다르면, 한국어 수정 요청만으로 외국어 페이지까지 함께 바뀌는지 확인이 필요하거든요. 이 부분은 미리 꼭 이야기해두시는 게 좋습니다.

저희 블링크애드에 다국어 홈페이지 제작을 문의하실 때도 **유지할 주소와 새 언어 영역, 메뉴 연결, 공개·복구 담당**을 함께 살펴보시면 됩니다. 지금 사이트에서 추가할 수 있는 범위를 확인한 다음, 제작할 페이지와 공개 일정을 맞춰가면 됩니다.

[홈페이지 제작사에 확인할 인수·운영 조건](https://www.blinkad.kr/blog/hospital-website-agency-checklist)도 함께 읽어보시면 도움이 됩니다. 현재 홈페이지 주소와 희망 언어를 알려주시면, [다국어 홈페이지 제작 상담](https://www.blinkad.kr/contact)에서 추가하려는 내용을 이야기하실 수 있습니다.
