# 병원 다국어 홈페이지 제작, 기존 사이트를 유지하면서도 가능할까요?

한국어 홈페이지는 그대로 쓰고 싶은데 외국어 페이지가 필요하신가요? 병원 다국어 홈페이지 제작을 알아보실 때 사이트 전체를 다시 만들어야 하는지부터 걱정되실 수 있습니다.

**현재 사이트에서 새 언어 페이지를 연결할 수 있다면, 한국어 홈페이지를 유지하면서 다국어 영역을 추가하는 방식을 검토할 수 있습니다.** 기존 제작사를 바로 바꿔야 하는 것도 아닙니다. 다만 제작 도구와 호스팅에서 허용하는 작업, 현재 운영 담당자의 협조 범위를 확인해야 가능한 방식을 정할 수 있습니다.

## 기존 홈페이지에서 무엇을 살리고, 무엇을 추가할까요?

우선 한국어 홈페이지와 외국어 페이지가 각각 해야 할 일을 나눠보시면 됩니다. 한국어 사이트가 현재 고객의 진료 안내와 문의를 잘 처리하고 있다면 그 기능을 유지하면서 외국인에게 필요한 내용을 추가하는 방향을 생각할 수 있습니다.

외국어 페이지는 안내할 고객과 진료에 맞춰 필요한 부분부터 제작하시면 됩니다. 어떤 고객에게 어떤 진료를 안내할지에 따라 시작할 범위가 달라지거든요.

예를 들어, 영어로 특정 진료를 알아보는 고객에게 안내하려면 해당 진료 설명과 의료진 정보, 위치·문의 방법을 함께 준비할 수 있습니다. 기존 한국어 원문과 사진을 활용할 수 있는지, 새로 보완할 내용은 무엇인지 살펴보는 겁니다. 자료의 사용 권한과 최신 여부도 병원에서 확인해주셔야 합니다.

| 유지·활용을 검토할 부분 | 추가·보완할 부분 |
|---|---|
| 현재 한국어 주소와 주요 진료·문의 기능 | 새 언어의 페이지와 주소 |
| 사용 가능한 병원·의료진 정보와 사진 | 외국인에게 설명할 진료·방문·문의 안내 |
| 기존 도메인과 운영 환경 | 언어 메뉴, 언어별 페이지 연결 |
| 기존 한국어 사이트의 관리 업무 | 외국어 정보 수정과 공개 후 확인 업무 |

이렇게 나누면 **이번에 필요한 추가 작업의 견적**을 요청하기 쉽습니다. 실제 비용은 추가 제작과 기존 시스템 연동 범위를 확인한 뒤 비교하셔야 합니다.

## 가능 여부는 제작 방식과 변경 권한을 보고 판단합니다

직접 파일을 추가할 수 있는 사이트와 제작 도구가 정한 기능 안에서만 수정할 수 있는 사이트는 작업 방법이 다릅니다. 현재 도메인 안에 새 페이지를 넣을 수 있는지, 언어 메뉴를 연결할 수 있는지부터 제작 담당이 살펴봐야 합니다.

병원에서 서버 설정 방법까지 알아보실 필요는 없습니다. 현재 제작사에 아래 내용을 전달해주시면 됩니다.

> 한국어 홈페이지는 유지하면서 외국어 페이지를 추가하려고 합니다. 현재 사이트에서 가능한 연결 방식과 필요한 설정 변경, 메뉴 수정에 협조할 수 있는 범위를 알려주세요.

영어 영역에 `/en/` 같은 주소를 쓰는 방법도 있지만 실제로 가능한지는 사이트 환경에 따라 달라집니다. Google은 언어마다 별도 URL을 사용하는 방식을 권장하며 하위디렉토리와 서브도메인 등 여러 구조를 안내합니다. 주소 구조만으로 검색 순위가 더 좋아진다고 약속할 수는 없습니다. [Google 다국어·다지역 사이트 안내](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)

기존 환경에서 추가가 어렵다면 다른 연결 방식을 협의하거나 기존 사이트 수정 범위를 넓혀야 할 수 있습니다. 이 확인을 거쳐야 기존 사이트를 얼마나 유지할 수 있는지도 답할 수 있습니다.

## 기존 제작사와 새 제작사가 달라도 진행할 수 있나요?

각자 맡을 작업과 필요한 협조가 합의된다면 검토할 수 있습니다. 새 제작사가 외국어 페이지를 완성해도 기존 메뉴에 연결할 권한이 없다면 기존 제작사나 병원 운영 담당 중 누가 메뉴 연결을 맡을지 정해야 합니다. 이 작업까지 일정에 포함해야 공개 시점을 맞출 수 있습니다.

| 담당 | 제작 전에 함께 정할 일 |
|---|---|
| 기존 제작사·운영 담당 | 가능한 연결 방식, 기존 메뉴·설정 수정, 변경 전 상태 보관과 복구 범위 |
| 다국어 추가 제작 담당 | 언어별 페이지 구성·제작, 필요한 연결 조건, 새 영역의 화면·링크 확인 |
| 병원 담당 | 사용할 자료와 공식 정보 확인, 희망 언어·진료 범위 결정, 문의 응대 방법과 공개 승인 |

사이트마다 운영 계약이 다르므로 기존 제작사의 추가 작업비와 협조 일정도 견적에 포함해 확인하시면 좋습니다. [홈페이지 제작사에 확인할 인수·운영 조건](https://www.blinkad.kr/blog/hospital-website-agency-checklist)도 참고하실 수 있습니다.

## 공개할 때는 기존 한국어 사이트도 함께 확인합니다

새 외국어 페이지와 기존 한국어 페이지를 오가며 언어 메뉴, 주요 진료 화면, 문의 버튼을 PC·모바일에서 확인해야 합니다. 외국어 안내가 병원에서 실제 응대할 연락 창구로 연결되는지도 함께 보시면 됩니다.

공개 후에는 페이지가 열리는지와 검색에 색인됐는지를 나눠 확인합니다. Google의 기술 조건을 갖춰도 색인은 보장되지 않으므로 제작 완료와 검색 확인은 따로 협의해두시면 좋습니다. [Google 검색 기술 요구사항](https://developers.google.com/search/docs/essentials/technical)
