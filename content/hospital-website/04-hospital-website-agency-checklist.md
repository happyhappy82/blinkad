# 병원 홈페이지 제작사에 확인할 검색·운영·인수 조건

홈페이지 제작사를 고를 때 포트폴리오와 견적서만으로는 판단하기 어려운 부분이 남습니다. 오픈 뒤 진료시간을 누가 바꾸는지, 리뉴얼 때 기존 주소는 어떻게 처리하는지, 계약이 끝나면 무엇을 받는지까지 확인해야 합니다. 계약 전에 검색 작업, 병원에서 수정할 범위, 계약 종료 시 인수할 자료를 구체적으로 적어두세요.

## 검색 작업은 적용 페이지와 검수 자료로 확인합니다

“검색에 잘 나오게 해드립니다”라는 설명을 들었다면 실제 작업 목록을 요청하세요. 진료별 페이지 구성, 페이지 제목과 설명, 검색 접근을 막는 설정의 점검, 사이트맵, 기존 주소의 이전 계획 중 어디까지 맡는지 구분해야 합니다. 리뉴얼이라면 현재 홈페이지의 주소 목록과 유지할 콘텐츠를 먼저 검토하는지도 물어보세요.

AI 검색을 고려한 개발도 구체적인 산출물로 확인합니다. 의료진 정보와 진료 설명을 어떤 페이지에 담는지, 핵심 내용이 이미지에만 들어가지 않는지, 질문과 답변을 관리자가 수정하는지 등을 짚어야 합니다. 적용할 페이지와 검수 방법을 합의하고, 오픈 후 실제 검색·AI 답변에서는 어떤 정보가 나오는지 따로 확인하세요.

## 병원이 원하는 변화부터 제작사와 맞춥니다

예약 문의가 목적이라면 모바일에서 진료 안내를 읽고 문의 화면에 도달하는 흐름을 봐야 합니다. 의료진의 전문 분야를 설명하려는 병원이라면 프로필과 관련 진료 페이지의 연결이 중요합니다. 병원은 우선순위를 정하고, 제작사는 그 목표에 맞춰 화면과 기능을 제안하는 방식이 낫습니다.

[Google의 SEO 업체 선정 안내](https://developers.google.com/search/docs/fundamentals/do-i-need-seo)도 사업 목표에 대한 이해, 변경 내용과 이유의 설명, 신규 제작·리뉴얼 초기의 검색 검토를 강조합니다. 제안서에서도 무엇을 바꾸고 왜 필요한지 설명하는지 살펴보세요.

## 오픈 후 수정할 사람과 권한을 정합니다

운영 담당자가 실제로 고칠 항목을 적어보세요. 진료시간, 의료진 약력, 휴진 공지, 진료 안내 문구를 병원에서 직접 바꾸려면 해당 기능이 관리자 화면에 있어야 합니다. 상담 단계에서는 관리자 화면 시연을 요청하고, 문구 수정과 새 페이지 추가가 각각 가능한지 확인합니다. 관리자 계정이 있다는 설명만으로 수정 범위를 판단하기는 어렵습니다.

직접 수정하지 못하는 항목은 유지보수 계약에서 처리 범위와 요청 절차를 정합니다. 월별 수정 건수나 작업시간에 제한이 있는지, 긴급 장애와 일반 변경 요청의 연락 창구가 다른지 살펴보세요. 보안 업데이트, 백업 주기와 보관 기간, 복구 요청의 담당자도 확인할 항목입니다. 병원 쪽에서는 콘텐츠 승인자를 정해 의료정보 검토가 빠지지 않도록 관리해야 합니다.
