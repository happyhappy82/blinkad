# 병원 홈페이지 리뉴얼, 기존 주소와 검색 유입을 지키는 이전 작업

리뉴얼 견적을 받을 때 디자인과 메뉴 구성은 꼼꼼히 살펴보지만, 기존 페이지 주소를 어떻게 처리할지는 놓치기 쉽습니다. 방문자는 병원 이름뿐 아니라 진료 정보를 검색해서도 찾아옵니다. 예전에 올린 진료 안내, 의료진 소개, 오시는 길을 저장한 링크로 다시 찾는 사람도 있습니다. 새 화면을 공개하는 날, 이 길들이 어디로 이어질지 정해야 합니다.

## 먼저 기존 주소와 새 페이지를 짝지으세요

도메인을 그대로 사용해도 메뉴를 합치거나 제작 플랫폼을 바꾸면서 개별 페이지 주소가 달라질 수 있습니다. 바꿀 이유가 없는 주소는 유지하는 방안부터 검토하세요. 제작사에 기존 주소 목록과 새 주소를 나란히 적은 ‘주소 대응표’를 요청하세요. 병원 담당자가 확인할 항목은 어렵지 않습니다. 기존 페이지의 내용, 새로 연결할 페이지, 유지·통합·삭제 여부, 확인 결과를 적으면 됩니다.

기존 ‘허리 통증 진료 안내’를 새 ‘척추 진료 안내’에 통합한다면, 새 페이지에 기존 방문자가 찾던 설명이 남아 있는지 살펴봅니다. 이름만 비슷한 페이지로 보내서는 검수가 끝나지 않습니다. 진료가 종료되어 대체할 내용이 없다면 무관한 곳으로 보내기보다 삭제된 페이지로 처리할지 협의해야 합니다.

목록은 현재 메뉴만 보고 만들지 마세요. 예전 사이트맵, 검색 유입이 있던 페이지, 외부에서 링크한 주소를 함께 확인합니다. 메뉴에서 빠진 오래된 안내문이나 다운로드 자료도 대상입니다. 특히 검색 방문이 많았던 진료 페이지는 표시해 두면 이전 후 먼저 점검할 대상을 고르기 쉽습니다.

## 자동 연결은 목적지와 방식까지 확인하세요

이전 주소에 접속한 사람을 새 주소로 자동 안내하는 처리가 리디렉션입니다. Google은 주소를 영구적으로 옮길 때 가능한 경우 서버 측 영구 리디렉션인 301 또는 308을 권장합니다. 병원 담당자가 설정 방법을 익힐 필요는 없습니다. 제작사에 적용 방식과 실제 도착 주소를 확인받으면 됩니다. 근거는 [Google 리디렉션 안내](https://developers.google.com/search/docs/crawling-indexing/301-redirects)에서 살펴볼 수 있습니다.

기존 주소를 모두 새 메인 화면으로 보내는 방식은 피하세요. 특정 진료 정보를 찾던 방문자가 메인 화면에서 내용을 다시 찾아야 하기 때문입니다. 여러 주소를 하나로 합칠 때도 내용을 실제로 통합한 페이지로 연결해야 합니다.

검수 자료에는 ‘연결 완료’ 한 줄 대신 기존 주소, 최종 도착 주소, 영구 이동 적용 여부, 오류 여부를 남겨 달라고 요청하세요. 중요한 주소는 병원 담당자도 직접 열어보고, 엉뚱한 진료 페이지나 오류 화면으로 도착하는 항목을 표시합니다. 이 표가 있어야 수정 요청과 재확인이 같은 기준으로 진행됩니다.

## 새 홈페이지 안의 주소도 바뀌어야 합니다

자동 연결을 설정했더라도 새 사이트의 메뉴와 본문 링크가 계속 이전 주소를 가리키면 정리가 덜 된 상태입니다. 제작사에는 내부 링크를 새 주소로 바꾸고, 검색엔진에 알릴 페이지 목록인 사이트맵도 갱신해 제출했는지 확인받으세요. 병원에서 관리하는 광고, 지도 서비스, SNS의 링크도 담당자를 정해 수정합니다.

오픈 전에는 새 페이지에 시험용 검색 차단 설정이 남지 않았는지, 이전 주소로 연결되던 이미지와 안내 자료가 열리는지도 확인해야 합니다. 디자인 검수와 별도로 주소 대응표의 처리 결과를 받으세요. 도메인을 바꾸는 경우에는 Search Console의 주소 변경 절차가 필요한지도 제작사가 검토하도록 요청합니다.

## 오픈 후 확인 기간까지 이전 범위에 넣으세요

Google은 새 주소를 다시 방문하고 처리하는 동안 일시적으로 검색 순위가 변할 수 있다고 설명합니다. 리디렉션을 잘 설정했다는 이유만으로 기존 순위와 유입이 그대로 유지된다고 약속할 수는 없습니다. 오픈 전 주요 페이지의 검색 클릭과 노출을 기록하고, 이후 새 주소의 색인 상태와 연결 오류, 유입 변화를 함께 살펴야 원인을 좁힐 수 있습니다.

누가 어떤 보고서를 확인할지, 오류가 발견되면 누구에게 요청할지, 점검은 언제까지 맡길지를 계약에 적으세요. 이전 주소의 자동 연결을 유지할 비용과 담당자도 남겨야 합니다. Google은 리디렉션을 가능한 한 오래, 일반적으로 최소 1년 유지하도록 권장합니다. 이전 주소의 연결을 유지할 환경을 마련한 뒤 기존 서버의 해지 여부를 판단하고, 도메인 갱신도 챙기세요.

[Google의 사이트 이전 안내](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes?hl=ko)를 기준으로 제작 범위를 점검해 보세요. 기존 홈페이지를 리뉴얼할 계획이라면 [블링크애드 상담](https://www.blinkad.kr/contact)에서 디자인과 함께 주소 이전, 검수 자료, 오픈 후 점검 범위까지 이야기해 주세요.
