# 병원 홈페이지 개선과 재제작, 작업 범위는 어떻게 달라질까?

AI 검색에 맞춰 홈페이지를 바꾸고 싶어도 기존 사이트를 어디까지 쓸 수 있는지 알기 어렵습니다. 오래된 화면이 마음에 걸릴 수도 있고, 새로 만드는 비용이 부담스러울 수도 있습니다.

이때는 홈페이지의 나이나 디자인보다 고쳐야 할 일을 먼저 보세요. 원고와 링크를 바꿀 일인지, 기능을 추가할 일인지, 사이트 전체를 다시 설계할 일인지에 따라 맡길 범위가 달라집니다.

## 불편한 점을 실제 작업으로 나눠봅니다

“홈페이지가 조잡하다”, “AI 검색에 불리해 보인다”는 말만으로는 견적을 받기 어렵습니다. 어느 화면에서 무엇이 불편한지 적어보세요.

예를 들어 의료진 정보가 오래됐다면 현재 정보를 확인하고 원고를 수정할 일입니다. 진료 안내를 이미지로만 올려두었다면 본문을 추가할 수 있는지 살펴봐야 합니다. 문의 버튼이 작거나 다른 페이지로 잘못 연결된다면 화면과 링크 수정이 필요합니다.

반면 원하는 페이지를 추가할 수 없거나, 문의와 접수 시스템을 새로 연결해야 한다면 개발 범위를 별도로 검토해야 합니다. 같은 홈페이지에서도 원고 수정과 기능 개발이 함께 필요할 수 있습니다.

## 현재 사이트에서 고칠 수 있는지 먼저 확인하세요

관리자 화면에서 어느 내용을 바꿀 수 있는지, 개발사가 수정할 수 있는 부분은 어디인지 확인합니다. 병원에서 바꿀 수 없다는 이유만으로 재제작이 필요한 것은 아닙니다. 기존 계약의 수정 범위와 권한을 확인하면 해결되는 경우도 있습니다.

검색 문제는 실제 점검 자료를 봐야 합니다. Google은 자바스크립트로 만든 페이지도 수집·렌더링·색인 과정을 거쳐 처리합니다. 특정 기술을 썼다는 설명만으로 전부 다시 만들어야 한다고 결정하기보다 필요한 본문과 링크가 전달되는지 확인하세요.

현재 사이트에서 제목·본문·링크·검색 설정을 수정할 수 있고, 수정 후 결과도 확인할 수 있다면 그 범위의 견적부터 받아볼 수 있습니다.
