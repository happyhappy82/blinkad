# 병원 홈페이지 제작비가 달라지는 작업 범위와 추가 비용

병원 홈페이지 견적을 비교할 때 총액만 나란히 놓으면 빠진 작업을 놓치기 쉽습니다. 같은 “진료 안내 10페이지”라도 병원이 자료를 모두 제공하는지, 제작사가 내용을 정리하고 새 화면을 설계하는지에 따라 맡기는 일이 달라집니다. 금액을 비교하기 전에 항목별 작업 범위와 오픈 뒤 지출을 먼저 맞춰보세요.

## 페이지 수와 화면 설계를 따로 확인합니다

페이지 수는 예상 작업량을 살펴보는 한 항목이지만, 그 숫자만으로 제작 범위가 정해지지는 않습니다. 같은 틀에 진료 내용만 넣는 페이지와 서로 다른 구성을 설계하는 페이지는 작업이 다릅니다. 견적서에 전체 페이지 수뿐 아니라 개별 디자인이 필요한 화면 수, 공통으로 사용할 양식, 모바일 대응 범위를 적어달라고 요청하세요.

메뉴 목록도 견적 전에 확정할수록 비교가 수월합니다. 의료진 소개, 진료 안내, 장비, 오시는 길을 각각 어느 수준으로 구성할지 병원에서 정해야 합니다. 지점별 페이지나 다국어 사이트가 필요하다면 번역, 별도 편집, 언어 전환 기능이 포함되는지 나눠 확인하세요. “반응형 포함”이라는 문구만 보지 말고 모바일에서 별도로 조정할 화면과 검수 기기를 합의해야 합니다.

## 원고·촬영·자료 이전은 별도 작업입니다

기존 소개문을 그대로 옮기는 일과 진료별 원고를 새로 구성하는 일은 다릅니다. 원고 기획, 집필, 의료진 검토 반영, 이미지 편집 중 제작사가 맡는 범위를 확인하세요. 촬영이 필요하다면 장소와 촬영 대상, 보정본 수량, 추가 촬영 조건도 견적에 드러나야 합니다. 병원은 의료정보를 확인할 담당자와 자료 전달 일정을 정해두어야 합니다.

리뉴얼에서는 기존 게시물과 사진을 얼마나 옮길지도 비용에 영향을 줍니다. 이전할 게시물 수, 첨부파일, 오래된 자료의 정리 주체를 목록으로 만들고 자동 이전과 수작업을 구분해달라고 하세요. 기존 주소가 달라지는 페이지는 어떤 주소로 연결할지 검토하는 작업도 필요합니다. 주소 이전 처리를 맡긴다고 해서 기존 검색 순위가 그대로 유지된다고 약속받을 수는 없습니다.

## 검색 대응은 항목과 검수 자료로 비교합니다

견적서의 “SEO·AI 검색 최적화” 한 줄로는 포함 범위를 알기 어렵습니다. 진료별 정보 구조 설계, 페이지 제목·설명 작성, 검색 접근 설정 점검, 사이트맵 구성 중 무엇을 제공하는지 물어보세요. 구조화 데이터가 제안됐다면 적용할 정보와 페이지, 검수 자료를 확인합니다. 적용 자체를 특정 검색 화면이나 AI 답변 노출의 보장으로 받아들이지 않아야 합니다.

병원과 제작사 사이에는 누가 정보를 작성하고 누가 검수할지도 정해야 합니다. 개발 항목에 원고 작성이나 정기 업데이트까지 자동으로 포함되는 것은 아니기 때문입니다. [Google의 SEO 업체 선정 안내](https://developers.google.com/search/docs/fundamentals/do-i-need-seo)는 신규 사이트나 리뉴얼을 계획하는 초기에 검색 전문가의 검토를 고려하라고 설명합니다. 화면 개발을 마친 뒤 별도 작업으로 추가할지, 처음부터 설계 범위에 넣을지 견적 단계에서 결정하세요.

## 제작비와 반복되는 운영비를 나눕니다

호스팅, 도메인 갱신, CMS 구독, 유료 플러그인, 문자 발송처럼 오픈 뒤에도 비용이 생기는 항목을 별도 표로 받아보세요. 각각 결제 주체, 갱신 주기, 포함 사용량, 초과 요금 조건을 확인해야 합니다. 부가세 포함 여부와 최초 계약 기간에만 제공되는 할인·무상 항목의 종료 조건도 비교에 필요합니다.

예약 시스템 연동은 외부 서비스 이용료와 홈페이지 개발비를 분리해서 봐야 합니다. 단순한 외부 예약 링크인지, 사이트 안에서 정보를 주고받는 연동인지에 따라 범위가 달라집니다. 또한 호스팅이나 CMS 이용료를 냈다는 사실이 맞춤 개발 소스의 소유·이전 권리를 정해주지는 않습니다. 소스 제공 여부와 제3자 라이선스 조건은 계약에서 별도로 확인하세요.

## 추가 비용은 변경 기준을 먼저 정합니다

계약 후 메뉴를 늘리거나 새 기능을 넣는 요청, 합의된 디자인을 바꾸는 요청은 추가 견적 대상이 될 수 있습니다. 수정 횟수만 묻기보다 초안 수정, 개발 오류 수정, 기능 추가를 어떻게 구분하는지 확인하세요. 추가 작업은 비용과 일정에 대한 병원 승인을 받은 뒤 진행하도록 절차를 정해두는 편이 좋습니다.

마지막으로 오픈 전 검수와 오픈 후 유지보수의 경계를 확인합니다. 오류 보완 기간, 정기 수정 범위, 계약 종료 시 자료 이전 지원은 각각 다른 조건입니다. 비교할 견적이 있다면 포함·제외·미정 세 칸으로 항목을 표시해보세요. [블링크애드 홈페이지 제작 문의](https://www.blinkad.kr/contact)에도 필요한 메뉴, 보유 자료, 예약 방식, 원하는 운영 범위를 함께 전달하세요. 총액을 묻기 전에 포함할 작업과 병원이 직접 맡을 일을 먼저 정리하는 데 도움이 됩니다.
