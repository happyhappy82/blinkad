# AEO·GEO 클라이언트 자료 입력 Form

- 공개 경로: `https://www.blinkad.kr/client-intake`
- 저장 위치: Notion `자료 저장 폴더` 하위 `AEO·GEO 클라이언트 자료 접수` DB
- 적용 대상: 신규·기존 블링크애드 클라이언트
- 목적: 목표 키워드, 실제 판매상품, 고객 질문, 고유 경험, E-E-A-T 증빙, 방문·외국인 응대 정보를 콘텐츠 제작 전에 한 번에 수집한다.

## 클라이언트 화면

1. 업체 기본정보
2. 브랜딩 목표
3. 핵심 상품·고객
4. 실제 고객 질문
5. 업체 고유 경험
6. 경력·수상·활동과 증빙
7. 방문·예약·외국인 응대
8. 자료 공유·공개 동의

## 운영 원칙

- 기존 클라이언트에는 이미 받은 내용을 다시 요구하지 않고 변경·추가·증빙 보완 위주로 안내한다.
- 계정 비밀번호, 주민등록번호, 진료기록, 고객·환자를 식별할 수 있는 정보는 받지 않는다.
- 파일을 Form 서버에 직접 보관하지 않는다. 클라이언트가 관리하는 Drive·Dropbox 등 공유 폴더 URL을 받는다.
- 브라우저 `localStorage`에 작성 중 초안을 임시 저장하고 제출 성공 시 삭제한다.
- 제출 결과는 Notion에 업체별 한 페이지로 저장하며 접수번호를 발급한다.
- 수상·자격·누적 수치·활동은 증빙 URL과 기준일을 확인한 뒤 콘텐츠에 반영한다.
- 개인정보 수집·이용 목적, 수집 항목, 보유 기간, 동의 거부 안내를 Form 안에서 고지하고 동의문 버전을 접수 건마다 기록한다.

## 개인정보 동의문

- 버전: `2026-09-25-v1`
- 보유 기간: 계약 종료 또는 마지막 업무 완료일로부터 1년
- 별도 법정 보존 의무가 있는 자료는 해당 법정 기간 적용
- 기준: 개인정보 보호법 제15조 제2항의 고지 항목

## 서버 환경

- `NOTION_TOKEN`: 기존 Vercel Production 환경변수 사용
- `BLINKAD_INTAKE_DATABASE_ID`: 선택값. 없으면 현재 접수 DB ID를 코드의 기본값으로 사용

## 검수

```bash
npx tsc --noEmit
npm run build
```

운영 배포 후 다음을 확인한다.

- `/client-intake` HTTP 200
- `noindex, nofollow` 메타
- 모바일·데스크톱 단계 이동과 필수값 검증
- 새로고침 후 작성 중 내용 복원
- 테스트 제출 후 Notion 본문·속성 저장
- 테스트 제출 페이지 삭제 또는 보관 처리
