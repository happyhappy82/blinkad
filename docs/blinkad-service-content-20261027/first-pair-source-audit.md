## 미확정 약속으로 바꾸면 안 되는 항목

- **언어·국가 지원**: 영어·일본어·간체·번체 모두 기본 포함 / 중국/대만/북미/유럽 전지역의 현지전문가 지원 / 원어민·의료전문번역가·통역 상시배정 → 희망 국가/언어와 병원이 실제 응대 가능한 언어를 상담 입력자료로 받고, 제작·검수 가능 범위를 확인한 뒤 합의한다. 자사사이트 언어버튼을 고객용 지원언어 보장으로 해석하지 않는다.
- **납기·운영량·지원시간**: 다국어사이트2주완성 / 정기발행편수·수정무제한 / 24시간상담/장애복구·24시간내모든답변 / 첫달정비=전체사이트납기 → 페이지범위·자료전달·병원검토·원제작사협의 후 일정을 합의한다고 쓴다. 기존 페이지의 효과관찰기간을 제작납기나성과보장으로 전용하지 않는다.
- **산출물·접근권한·기능**: 모든계약에원본소스·CMS·전체계정인수보장 / GTM/GA4/CRM/API예약연동기본포함 / 정해진사진촬영수량·게시/보고서파일형식 / 특정AI4종에동일표본측정기본포함 → 요청범위와 확인방법을 상담/작업명세에서 정한다. 정보글이 권하는 자료목록은 확인할 예시이며 자사확정납품약속으로 단정하지 않는다.
- **가격·계약조건**: 제작비·월요금·할인·고정계약기간 / 서버/도메인/번역/촬영비모두포함 / 무료수정기간·해지/인계조건 확정 → 현재URL·필요페이지·언어·원자료·운영조건을 받은 뒤 포함/제외범위를 합의하고 견적을 정한다. 실제 숫자는 제공된 견적 정본이 있을 때만.
- **의료·유치·응대 부가서비스**: 환자소개·알선·방문예약확정대행 / 통역·비자·픽업·환불중재·상담인력운영 / 의료진검수·의료광고심의/법률승인대행기본제공 → 디지털정보·검색·페이지·콘텐츠 작업과 병원의 의료정보 승인·응대·예약/진료 판단을 분리한다. 개별 법적요건 판단은 이 감사 범위 밖.
- **성과·개발호환성·실제사례**: AI인용/순위/문의/예약증가보장 / 어떤서버든원사이트영향없이추가가능 / 하위디렉토리면SEO가무조건유리 / 가상의병원시공/성과를실사례처럼소개 → 원사이트 기술·접근·승인·배포/복구조건을 확인한 후 가능한안과 제한을 설명한다. 기존 공개페이지의 연구수치/기간/강한주장은 이 감사에서 재검증하지 않았으므로 새 원고의 성과근거로 자동복제하지 않는다.

## H03의 새 중심 질문

**기존 한국어 홈페이지를 운영하면서 다국어 영역을 추가할 때, 기존 제작사·추가 제작사·병원이 경로·메뉴·배포·검수·복구·정보갱신을 어떻게 나눌 것인가?**

비교표는 확인용 예시다. 실제 서버/접근/계약을 확인하기 전 가능 여부·납기·무영향을 약속하지 않는다.
