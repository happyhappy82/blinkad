# 묶음9 N02 — 병원 비교 후보 선정의 실제 검색·공식 안내 표본

확인일: 2026-10-27 KST. 집필·기획 원본 변경·의료 추천·폼 제출0. 표본은 마케팅 비교 대상 선정 방법을 설명하기 위한 자료다.

## 잠근 주제

제목: `병원 외국인 마케팅 경쟁분석, 같은 지역 병원만 비교해도 될까요?`

결정: 반경 안의 병원 목록만으로 끝내지 않고, 실제 검색 질문과 공식 진료·언어·방문 조건을 확인해 **마케팅에서 비교할 병원의 범위**를 정한다. 의료 효과·치료 적합성·좋은 병원을 선정하는 글이 아니다.

## 실제로 실행한 검색과 관측 조건

- 검색식: **`LASIK Seoul English consultation`**.
- 도구: 통합 웹 검색 도구의 `search_query`. 영어로 검색했다.
- 국가·위치: 국가 필터·검색 위치·로그아웃 Google 환경을 통제하지 않았다. **Google 미국/한국 실순위·국가지정 실측이 아니다.** 제목에 영어가 있다는 이유로 특정 국적의 실제 검색 수요를 측정했다고 쓰지 않는다.
- 확인일: 2026-10-27 KST. 통합 결과에서 병원 브랜드의 영문 안내·국제환자·문의 페이지 등이 반환됐다. 반경 지도 결과와 동일한 목록인지, 환자가 실제로 이 후보를 선택했는지는 측정하지 않았다.
- 의도 해석: 검색어에 진료(시력교정), 지역(서울), 이용 조건(영어 상담)이 함께 있다. **이는 이 검색식의 편집상 해석**이며 월 검색량·전체 고객 의도·문의 빈도 자료가 아니다.

## 공식 병원 안내2곳에서 확인한 비교 항목

|병원 브랜드·출처|공개 페이지에서 확인한 것|마케팅 비교표에 남길 이유|확인하지 않은 것|
|---|---|---|---|
|[St. Mary's Jin Eye Center 국제환자 안내](https://jin-eye.co.kr/en_us/international-patients/)|영문 국제환자 페이지, 시력교정 등 진료 메뉴, 영어 상담/진료 안내를 포함한 병원 자체 설명, 온라인 상담·문의 연결|이 검색식에 맞춰 어떤 진료·언어·방문 안내를 제공하는지 확인할 수 있음|실제 영어 담당자 근무·예약 가능일·통역/공항서비스 수행·가격·치료 효과·의료 수준은 검증하지 않음|
|[B&VIIT 공식 영문 홈페이지](https://english.bnviit.com/)|영문 Medical Services의LASIK/SMILE/LASEK 등 메뉴, 온라인 검사 예약·연락 안내, 위치 안내 링크|같은 검색식에 대해 진료별 설명과 예약·문의 정보를 어느 페이지에서 찾는지 비교 가능|실제 상담·예약 실행·가격·회복/수술 효과·사이트에 기재된 누적 실적의 독립 검증은 하지 않음|

B&VIIT의 영문 사이트 관계는 [한국어 공식 홈페이지](https://www.bnviit.com/)의 **English 링크가 `english.bnviit.com`을 가리키는 것**으로 확인했다. 영어 페이지를 GET해 제목과 본문을 읽었다. 검색 결과에 등장한 별도 브랜드 도메인을 도메인 소유까지 검증한 공식 사이트라고 단정하지 않고 이 공식 언어 링크로 추가 확인한 것이다. 이 영문 사이트가 통합 검색의 몇 위였다고 기록하지 않는다.

두 영문 원문은 직접GET200이었다. 위 사실은 **공개 안내의 존재와 자체 설명**이며 실제 이용 조건을 보증하는 독립 조사 결과가 아니다. 두 곳의 수술 실적·장비·인증·가격·의료진 우열은 글의 판단 근거로 사용하지 않는다. 두 병원 모두가 어떤 특정 병원의 실제 경쟁사라는 결론도 아니다.

## 원고에 사용할 선정표의 기준

검색식/언어 → 반환된 후보·발견 경로 → 공식 사이트의 같은 진료 안내 → 영어·방문·문의 조건의 확인 위치 → 비교에 포함한 이유 → 남은 미확인 항목을 적는다. 목표 고객이 다른 질문을 한다면 같은 반경이라도 비교표가 달라질 수 있다는 설명에 사용한다. 조건이 다르거나 공식 안내가 부족하면 '확인 필요'로 남기고 임의로 지원한다고 채우지 않는다.

이는 **공개 정보를 비교할 조사 양식**이다. 특정 환자에게 어느 수술/병원을 추천할지 판단하거나 거리와 상관없이 특정 병원이 더 잘한다고 평가하지 않는다. 실제 의료 상담은 하지 않았다.

## 기존 글과의 경계·자사 실제 제공 범위

- 기존 대형병원 영문 안내 글은 환자가 무엇을 확인하는지, 거주/의료관광 환자 글은 대상과 안내를 어떻게 나누는지를 다룬다. N02는 **마케팅 담당자가 조사할 비교 후보의 포함/제외 이유**를 정하는 질문이다.
- [블링크애드 외국인마케팅](https://www.blinkad.kr/foreign-marketing)을10/27 재열람·GET200 확인했다. 브랜드명·업종·지역 검색/지도와 경쟁 업체를 확인하는 현재 노출 진단, 프로필 정비·리뷰·콘텐츠·웹사이트 연결을 공개한다.
- 이 서비스 설명은 현재 제공 범위 자료다. 모든 검색엔진·국가·언어를 전수 조사하거나 특정 병원의 순위·수요·예약 증가를 보장한다는 뜻은 아니다. 병원 유치 중개·통역·비자·상담 인력 운영을 제공한다고 확대하지 않는다.
- 링크는 현행 브리프의 `/foreign-marketing` 본문 UTM와 `/contact` 상담 UTM을 유지한다. H02 서비스 안내의 실제 공개 URL은 아직 미확정이므로 추측 주소로 바꾸지 않는다.

이번 관측으로 국가별 검색량·시장 점유율·현재 Google 순위·병원 선택률을 만들지 않는다. 통합 도구 결과와 직접 공식 페이지 확인의 차이를 원고 근거에 남긴다.
