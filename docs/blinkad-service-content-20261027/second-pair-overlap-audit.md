## H01 · 프랜차이즈 구글맵 관리 대행

**새 질문은 '누가 프로필 정보를 수정 요청하고, 누가 내용을 확인하고, 누가 게시를 승인할까'다.** 기존 대행사 선정 글의 소유권·동의·월 작업표·권한 인계를 길게 다시 설명하면 중복된다.

- 본사 공통 정보와 매장별 영업시간·휴무·제공 서비스처럼 실제 매장에서 확인할 정보를 나눈다.
- 본사·직영점·가맹점·대행사가 사전에 맡기로 한 업무와 현재 Google 접근권한을 각각 확인한다. 프랜차이즈를 직영 체인과 동일시하지 않는다.
- 한 수정 요청의 전달→사실 확인→승인→반영 확인을 담당표로 설명한다. 이 표는 **운영 예시**이며 Google의 내장 승인 기능이나 모든 계약의 확정 산출물이 아니다.
- 담당자가 바뀔 때 Google 접근권한과 아직 처리하지 않은 수정 요청·승인 기록을 인계한다. 계약상 권리나 본사의 가맹점 소유권을 판단하는 글로 넓히지 않는다.

현재 자사 페이지에서 확인되는 업무는 **프로필 정비, 한국어·외국어 리뷰 응답, 사진·게시물, 웹사이트·콘텐츠 연결, 월간 리포트**다. 프랜차이즈 통합 승인 시스템·전 가맹점 자동 접근권한·실시간 통합 대시보드·승인 SLA·전용 실적/요금은 공개 설명에서 확인되지 않는다.

링크는 기존 기획대로 [구글맵 운영 서비스](https://www.blinkad.kr/google-map-marketing)와 [프랜차이즈 구글맵 관리 상담](https://www.blinkad.kr/contact)을 쓸 수 있다. 후자는 일반 문의 페이지로 연결되며 프랜차이즈 전용 폼으로 부르지 않는다.

이전 인벤토리의 `GBP 관리 대행 서비스 완벽 가이드`에는 지점 수가 비용 변수라는 설명이 있고, 등록글 `#N2 다지점·MSO`는 상담채널 관리 문제다. H01은 비용·상담 통합이 아닌 **프로필 변경의 확인·승인 업무**를 유지한다.

## H05 · 방한 전과 국내 체류 고객의 구글광고

**새 질문은 '어떤 운영 조건이 다르면 캠페인·위치 옵션·예산을 나눠야 할까'다.** 기존 광고 전 준비 글을 다시 쓰거나, 영어 광고가 외국인 국적을 가르는지의 결론으로 돌아가지 않는다.

- 해외에서 방한을 계획하는 검색과 국내에서 방문할 곳을 찾는 검색을 예로 들되, 위치만으로 방문 계획·국적·여행객 여부를 확정하지 않는다.
- 광고를 내보낼 위치 조건, 언어, 검색어, 필요한 안내, 예산을 각각 비교한다. 국내 체류를 단기 여행객과 같다고 쓰지 않는다.
- 예산·설정·안내·보고를 달리 관리할 이유가 있을 때 분리 여부를 판단한다. 모든 경우 분리·예산 증액·고정 배분을 권하는 답은 아니다.
- 운영 후 비교할 검색어·문의·기간을 구분하고, 방문 예정 시점이 다른 문의를 단순한 예약 수로 바로 평가하지 않는다.

현재 `/google-map-marketing` FAQ는 **블링크애드가 Google Ads도 운영한다**고 명시한다. 기존 광고 전 준비 글은 지도·랜딩·문의 수신을 점검한 뒤 광고 범위를 정한다고 설명한다. 다만 방한 단계별 분리 캠페인의 실제 성과나 특정 국적 식별 기술·확정 예산을 입증하는 자료는 아니다.

기존 `BLK-BRAND-20` 기획은 광고 언어와 국적의 구분, 관광객 검색 채널 글은 한국 방문 전후의 정보 탐색, 명동 피부과 글은 체류 일정·예약 안내를 다룬다. 필요한 배경으로 짧게 연결하되 새 글의 중심은 **캠페인을 나눌 운영상 이유**다.

주 링크는 [비용을 결정하는 항목](https://www.blinkad.kr/blog/gugeul-goanggo-biyong-ueol-eolmamyeon-hyogoa-bol-su-iss-eulkka-eobjongbyeol-hyeonsil-jeongli)과 [외국인 대상 구글광고 상담](https://www.blinkad.kr/contact)이다. 광고비 글의 **CPC 범위·전환율3% 시뮬레이션·CPA 과금 일반화 등은 이번에 공식 자료로 검증하지 않았으므로 새 원고에 인용하지 않는다.** 기존 글의 금액을 현재 견적이나 예상 문의량으로 사용하지 않는다. 실제 광고 준비를 더 살펴볼 독자에게만 기존 '광고 전 준비' 글을 추가 관련 읽기로 사용할 수 있다.
