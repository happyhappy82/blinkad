## 반영한 표현

- H02 ‘운영을 안내합니다’ → ‘맡길 수 있는 업무는 … 운영입니다.’ 실제 문의할 대상을 바로 설명.
- H02 ‘현재 문제를 아래 업무와 대조해 보세요’ → ‘아래에서 우리 병원에 해당하는 항목을 찾아보세요.’
- H02 ‘모든 계약에 일괄 적용하기보다’ → ‘이번에 맡길 업무에 맞춰 받을 자료와 완료 조건을 정하세요.’ 앞 문단의 협의용 예시 조건은 유지.
- H03 ‘진료 안내의 대응’ → ‘진료별 페이지 연결’.
- H03 ‘협의하는 순서가 좋습니다’ → ‘추가할 수 있는 범위를 확인한 뒤, 제작할 페이지와 공개 일정을 정하세요.’
- H03 ‘원사이트’를 ‘기존 사이트/기존 한국어 사이트’로 교정.

## 집필 근거와 한계

자사 공개 서비스는 자사 제공범위의 근거다. 실적·효과의 독립 증거로 사용하지 않았다. Google 문서는 Google 검색의 설명에만 사용했다. 작업별 담당표는 운영 양식이며 Google의 강제 조직표나 특정 병원에서 완료한 사례가 아니다.

원고2건의 내부 편집 검토이며 사용자 승인·의료진 검수·홈페이지 게시를 의미하지 않는다. 특정 병원의 서버·계약·계정에 접근하지 않았다. 썸네일·이미지 제작, Notion/고객 포털 저장, 기존 예약 수정, 외부 발행·배포는 실행하지 않았다.
