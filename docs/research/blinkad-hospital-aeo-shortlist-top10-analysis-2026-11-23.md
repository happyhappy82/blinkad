| 4. 사이트 나머지9개 | 한 업체씩 홈페이지·노출된 페이지·콘텐츠·E-E-A-T·기술 요소를 분석하고 3개씩 중간 비교한다. 겹치는 업체의 공통 자료는 재사용한다. | 10개 사이트 보고서. 실제 검색 노출 근거가 없는 경우 분석 한계를 별도 표시한다. |
| 5. 미확인 항목 재검증 | 가격 조건·회사 동일성·사례 수치·실제 산출물·외부 평판의 출처를 재대조한다. 이 검증은 각 업체 조사 때도 진행하고 마지막에 남은 공백만 점검한다. | 공개 확인/자사 주장/해석/미확인 구분, 비교 조건 일치. |
| 6. 종합 비교·적용 우선순위 | 상품·가격·작업 방식과 사이트·콘텐츠 특징을 각각 비교하고 블링크애드 적용 우선순위를 제안한다. | 경쟁사 종합표, 상품 기획 시사점, 홈페이지 개선 후보, 콘텐츠 기회 목록. |

### 상품 조사표

- 타깃 병원/국가/언어, 상품 포지셔닝, 단독 AEO/GEO와 기존 병원마케팅 패키지 포함 여부.
- 진단 → 질문/키워드 선정 → 콘텐츠 제작·의료 검수 → 홈페이지 기술 개선 → 외부 채널 → AI 측정 → 보고/개선의 실제 공개 과정. 인력/도구/자동화·검수 범위는 확인 가능한 만큼만 적는다.
- 월 콘텐츠 개수·언어·채널, 웹 수정 범위, 납품 보고서/대시보드, 일정, 병원 참여 범위, 사이트/콘텐츠/계정 소유·이관 조건.
- 공개 가격과 실제 견적서를 구분한다. 초기비·월 관리비·VAT·광고비·필수 옵션·최소 계약기간·해지 조건을 나누고 조건이 확인되면 최소 계약 총비용을 계산한다. 미공개 가격은 임의 추정하지 않는다. 견적 문의/메시지는 이번 계획에 따라 발송하지 않는다.
- 성과 사례의 고객명/기간/비교 기준/지표/원자료 확인 여부. 업체의 자체 성공 주장과 독립적으로 확인한 성과를 구분한다.

### 사이트·콘텐츠 조사표

- 실제 검색 노출 URL부터 보고 홈페이지, 서비스/가격, 회사/담당자 소개, 사례, 칼럼, 문의 페이지로 확장한다. 광고로만 노출된 업체의 광고 노출을 SEO/E-E-A-T 성과로 해석하지 않는다.
- 사이트 메뉴·콘텐츠 목록을 먼저 수집하고 핵심 페이지와 대표 콘텐츠를 심층 검토한다. 초기 표본은 실제 노출 페이지와 최신/핵심 주제 글을 포함하며 조사 범위·표본 수·추가 탐색 이유를 기록한다. 모든 글을 읽었다고 보고하지 않는다.
- 콘텐츠: 병원 담당자의 어떤 질문에 답하는지, 주제군·독창적 데이터·구체적 사례·출처·수정일·내부 링크·상담 이동을 본다.
- Experience: 실제 병원 프로젝트의 작업 과정·기간·결과·원자료. Expertise: 작성자/실무팀 경력·전문 설명·근거. Authoritativeness: 확인 가능한 외부 인용·업계 활동·관련 링크. Trust: 회사/연락처/작성 주체·성과 수치의 조건·출처·계약/가격 정보의 투명성. 로고/자사 홍보 문구만으로 실적을 확정하지 않는다.
- 병원 마케팅 대행사의 전문성을 평가한다. 환자용 의학 콘텐츠가 있으면 해당 내용에 필요한 의료 근거·검수도 별도로 확인한다.
- 검색 의도와 문서 적합성, 제목/H1, 내부 링크, 수집/색인 가능 여부, canonical/중복, 모바일 사용성 등은 E-E-A-T와 구분해 기록한다. 구조화 데이터의 존재만으로 상위 노출이나 AI 인용을 보장한다고 판단하지 않는다.
- 외부 데이터가 충분하지 않으면 순위 원인을 단정하지 않는다. 관측한 사이트 특징, 외부에서 검증한 근거, 검색 노출 기여 가능성에 대한 가설을 구분한다. Google E-E-A-T를 네이버의 단일 공식 점수로 적용하지 않는다.

방법론 근거 확인일 2026-11-23: [Google 사람 중심 콘텐츠/E-E-A-T 공식 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)는 E-E-A-T 자체가 단일 순위 요소는 아니라고 설명한다. [네이버 검색엔진 최적화 안내](https://searchadvisor.naver.com/guide/seo-basic-intro)는 수집·검색 반영과 콘텐츠/구조의 기본 점검을 안내한다.

다음 실제 조사 권고: 1단계 기준 대조와 2단계 하룹 시범 분석을 함께 시작한다. 6단계는 제안한 진행 방식이며 전 단계 실행 완료 또는 사용자 최종 승인으로 기록하지 않는다.
