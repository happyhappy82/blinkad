## 5. 공통 조사 기준

### 상품 조사

- 대상 병원·진료과·국가·언어, 단독 상품/종합 패키지/옵션 구분.

- 콘텐츠 수·형식·언어·채널, 웹 수정·영상·월 보고, 담당 역할·외주·도구·병원 참여.
- 초기비·월비·VAT·광고비·옵션·최소 계약기간·해지·자산/계정 소유·이관. 공개 정가/시작가/이벤트/실제 견적을 구분한다. 비공개는 미확인이며 임의 평균 견적을 만들지 않는다.
- 조건이 확인되는 경우 최소 계약 총비용을 계산한다. 다른 납품량/기간을 같은 상품 가격처럼 비교하지 않는다.
- AI측정은 제공사/질문/반복/웹검색/지역/언어/기간/원자료 조건을 확인한다. 자사 설명을 실제 측정 재현으로 보고하지 않는다.

### 사이트·콘텐츠·E-E-A-T 조사

- 실제 노출 URL을 출발점으로 홈페이지·서비스·가격·회사/담당자·사례·칼럼·문의로 확장한다.
- 메뉴·제목/URL 목록으로 주제군을 확인하고 실제 노출 글·최신 글·핵심 주제 글을 대표 표본으로 읽는다. 표본 수·선정 이유·미확인 범위를 남기며 전 글 심층 분석으로 과장하지 않는다.
- 경험: 실제 병원 프로젝트 수행 과정·기간·결과·원자료. 전문성: 작성자/담당팀 실무 경력·전문 설명·방법·근거. 권위: 관련 외부 인용·업계 활동·제3자 확인. 신뢰: 회사/연락처·작성 주체·성과 조건·출처·가격/계약 투명성.
- 회사 로고·실적 숫자·유료 기사·자사 배포자료만으로 독립적 신뢰를 확정하지 않는다. 환자용 의학 콘텐츠가 있는 경우에만 해당 글의 의료 출처/검수 조건도 별도로 본다.
- 검색 의도·내용, 제목/H1·내부링크·수집/색인·canonical/중복·모바일·구조화데이터는 E-E-A-T와 함께 살피되 다른 항목으로 기록한다.
- 관측 사실 / 자사 주장 / 교차 확인 / 해석·가설 / 미확인 / 해당 없음으로 구분한다. 임의 E-E-A-T 점수·순위 기여율은 만들지 않는다.
