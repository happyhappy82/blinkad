## 3. E-E-A-T를 해석한 기준

| 구분 | 관측할 수 있는 근거 | 이번에 확정하지 않은 것 |
|---|---|---|
| 경험 | 작업 순서·실무 판단·프로젝트 이야기·인터뷰 게시 | 익명 수치의 진실성·동시 요인을 뺀 인과 효과 |
| 전문성 | 설명의 구체성·작성/검수 주체·경력/저서·서식/계산 | 회사 대표 공개만으로 모든 글의 집필·의료 검수 완료 |
| 권위 | 관련 외부 저자 목록·원문 인터뷰·기관 자료·공식 명부 | 자사 로고/보도자료/제휴 소개를 독립 성과 인증으로 사용 |
| 신뢰 | 회사 식별·출처·날짜·예시 표시·조건·자산/거래 설명 | 수상 분야와 무관한 역량 보증·실제 계약/예약 이행 |

Google은 E-E-A-T 자체를 특정 순위 요소로 설명하지 않으며, 작성자가 누구이고 어떻게 만들었는지와 콘텐츠의 고유성·정확성을 평가할 수 있도록 안내한다. 이번 결과는 이 관점의 **정성적 관측**이고 네이버의 공식 점수나 임의의 100점 평가가 아니다. [Google 공식 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=ko)

## 4. 기술 SEO에서 구분해야 할 사항

- **시월 글 canonical → 홈:** 세 글에서 직접 확인. 실제 Google 선택 canonical·색인 상태는 별도 미확인.
- **애드리절트·리앤메디 HTTP 접근 제한:** 리더로 본문은 읽었지만 원본 태그/robots/sitemap 상태는 판정하지 않았다. 조사 도구의 접근 제한을 Googlebot 차단이나 사이트 미운영으로 바꾸지 않았다.
- **골드닥터스 sitemap 응답의 noindex:** XML 응답에 붙은 헤더이며 일반 페이지 전체의 noindex 증거가 아니다.
