## 기술 SEO·문의 연결

홈·서비스·공지 표본은 H1 1개·canonical·viewport와 조직/문서 JSON-LD를 가진다. sitemap.xml 응답의 X-Robots-Tag:noindex는 XML 자체에 붙은 것이며 본문 페이지에서 같은 헤더를 확인한 것은 아니다. 사이트 전체 noindex로 판단하지 않는다.

같은 업체의 실제 수집된 HTML에서 확인한 값은 다음과 같다. 페이지마다 설정이 다를 수 있다. robots 허용·HTTP200·사이트맵 포함·태그 존재는 실제 색인/순위/AI 인용을 보장하지 않는다.

|---|---:|---|---|
| [C09-A01](https://golddoctors.co.kr/news/20/) | 1 | https://golddoctors.co.kr/news/20/ | BreadcrumbList, ContactPoint, Country, ImageObject, ListItem, NewsArticle, Organization, Person, PostalAddress, WebPage, WebSite | 있음 / 있음 |
| [C09-S01](https://golddoctors.co.kr/) | 1 | https://golddoctors.co.kr/ | ContactPoint, Country, ImageObject, Organization, Person, PostalAddress, WebPage, WebSite | 있음 / 있음 |

## 검색 노출을 설명할 수 있는 범위

가설: 추천사와 회사의 실체를 먼저 보여 주고 문의로 넘기는 영업 구조다. 기존 기록의 Google·네이버 노출은 광고이므로 상위 자연검색이나 E-E-A-T 효과를 입증하지 않는다.

**미확인:** Search Console 실제 색인·Google 선택 canonical·백링크/참조 도메인·클릭/문의/예약 원자료·모바일 실화면·Core Web Vitals. 따라서 순위 기여율·E-E-A-T 점수·성과 우열을 산출하지 않았다.
