## 기술 SEO·문의 연결

직접 HTTP는 접근 제한이어서 원본 title/H1/canonical/JSON-LD·robots/sitemap의 정상 여부를 판정하지 않았다. 리더의 본문·목록·제목은 읽었지만 리더가 돌려준 제목을 원본 태그 검사로 바꾸지 않는다. 초기 AI병원추천 글은 이미지 중심 반환으로 본문 전수 검토에서 제외했다.

같은 업체의 실제 수집된 HTML에서 확인한 값은 다음과 같다. 페이지마다 설정이 다를 수 있다. robots 허용·HTTP200·사이트맵 포함·태그 존재는 실제 색인/순위/AI 인용을 보장하지 않는다.

| 표본 | H1 수 | canonical | 구조화 유형 | description / viewport |
|---|---:|---|---|
| 원본 HTML | 접근 제한으로 미확인 | 미확인 | 미확인 | 미확인 |

칼럼에서 선택 기준을 읽고 회사·영상·상품을 확인한 뒤 Tally 상담으로 이동한다. 문의를 실제 제출하지 않았으므로 접수 성공·예약 전환은 확인하지 않았다. [C02-WHOME](https://adresult.kr/) [C02-WA1](https://adresult.kr/93/?bmode=view&idx=175878076)

가설: 대표 경력·병원 주제 집중·진료과별 상품·실무 선택 글의 연결이 방문자의 업체 비교를 돕는다. 과거 홈페이지 자연검색 노출은 확인되지만 이 요인들의 순위 기여량이나 칼럼의 유입 기여는 알 수 없다.

**미확인:** Search Console 실제 색인·Google 선택 canonical·백링크/참조 도메인·클릭/문의/예약 원자료·모바일 실화면·Core Web Vitals. 따라서 순위 기여율·E-E-A-T 점수·성과 우열을 산출하지 않았다.
