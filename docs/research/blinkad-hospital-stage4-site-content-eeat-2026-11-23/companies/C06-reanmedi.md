## 기술 SEO·문의 연결

직접 HTTP 접근 제한으로 원본 H1·메타·canonical·구조화 데이터와 robots/sitemap을 기술 감사하지 못했다. 리더의 본문 제목·FAQ 형식과 원본 태그 존재를 혼동하지 않는다. 중복 구간은 별도 duplicate-content-check.json에 해시·범위를 기록했다.

같은 업체의 실제 수집된 HTML에서 확인한 값은 다음과 같다. 페이지마다 설정이 다를 수 있다. robots 허용·HTTP200·사이트맵 포함·태그 존재는 실제 색인/순위/AI 인용을 보장하지 않는다.

| 표본 | H1 수 | canonical | 구조화 유형 | description / viewport |
|---|---:|---|---|
| 원본 HTML | 접근 제한으로 미확인 | 미확인 | 미확인 | 미확인 |

짧은 기준→원장 체크→FAQ→현재 자료/어려움 상담→카카오와 공식 문의로 연결한다. 링크 목적은 확인했지만 실제 접수·응답은 시험하지 않았다. [C06-WA1](https://www.reanmedi.com/INSIGHT/?bmode=view&idx=175750500) [C06-WA3](https://www.reanmedi.com/INSIGHT/?bmode=view&idx=175750498)

## 검색 노출을 설명할 수 있는 범위

가설: 병원 내부 담당자가 바로 해결하려는 작고 구체적인 질문을 넓게 다루고 다음 상담을 연결한다. 글 수 증가나 반복 형식만으로 검색 성과를 추정할 수 없으며, 서로 다른 주소의 유사 글 역할부터 정리할 필요가 있다.

**미확인:** Search Console 실제 색인·Google 선택 canonical·백링크/참조 도메인·클릭/문의/예약 원자료·모바일 실화면·Core Web Vitals. 따라서 순위 기여율·E-E-A-T 점수·성과 우열을 산출하지 않았다.
