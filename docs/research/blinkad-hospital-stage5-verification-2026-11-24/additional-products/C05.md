# 오른기획 — 추가 확인한 병원 AI 검색 상품 범위

고정 ID **C05** · 확인일 **2026-11-24** · 분류 **동일 기능 제공 표시 확인 / 세부 명세 제한**

기존 12개 고정 표본을 소급 수정하지 않고 추가 확인 기록으로 보존한다. 14개 모두 같은 수준의 견적/계약을 확보했다는 뜻은 아니다.

## 확인한 연결

공식 칼럼 홈에서 AI 마케팅 카드와 `oreun.net/hospital_marketing/ai/` 연결을 확인했다. 공식 연계 oreunplan 글은 병원 GEO를 환자 질문의 답, 원장 판단, 채널 정보 일치, 단정/비교를 피한 설명으로 소개하고 병원 진단을 제안한다. 가상 A/B 비교이며 실제 반복 측정 결과는 아니다. [C05-V02](https://blog.oreun.net/) [C05-V03](https://blog.naver.com/PostView.naver?blogId=oreunplan&logNo=224478115501)

공개 방식: 진료/판단 정보 수집 → 질문 중심 설명 → 채널 정보 일치 → AI가 참고할 근거 정비. 사이트의 AI 메뉴는 판매 표시로 볼 수 있지만 상세 페이지는 접근 제한이다. 월 글·기술 수정·외부 게시·AI별 질문/모델/반복·보고·전담 조직·가격·VAT·약정·해지/소유권은 이번 공개자료로 확정하지 못했다.
