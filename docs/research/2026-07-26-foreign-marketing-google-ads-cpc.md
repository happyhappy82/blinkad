# 외국인 마케팅 Google 검색광고·CPC 조사

- 기준일: 2026-07-26
- 지역·언어 기준: 대한민국, 한국어, Google 검색
- 조사 대상 검색어: `외국인 마케팅 업체`

## 핵심 결론

1. 캡처 화면은 Google 검색결과 상단에 표시되는 **검색 텍스트 광고**다.
2. 첫 번째 광고에는 하위 페이지로 연결되는 **사이트링크 애셋**이 함께 노출됐다.
3. 화면만으로 경쟁사의 실제 CPC, 최대 입찰가, 캠페인 유형은 확인할 수 없다.
4. 블링크애드 계정의 `블링크애드 클라이언트유치` 검색 캠페인은 현재 중지 상태이며, 2026-04-27~2026-07-26 기간에 노출·클릭·비용이 없다.
5. 해당 캠페인의 수동 CPC 기준 입찰가는 키워드별 1,000원으로 설정돼 있다. 이는 **설정 입찰가**이며 시장의 실제 CPC나 상단 노출 보장 단가가 아니다.

## 캡처 광고 판별

- 형식: Google 검색 텍스트 광고
- 광고 문안: 반응형 검색광고 형태
- 추가 요소: 사이트링크 애셋
- 과금: 일반적인 검색광고는 클릭이 발생할 때 실제 CPC가 부과된다.
- 주의: 동일한 표시 형식이 검색 캠페인 외의 다른 캠페인 유형에서 송출될 수도 있으므로 캡처만으로 캠페인 내부 유형까지 확정할 수 없다.

## 운영용 테스트 입찰 제안

아래 값은 Google 키워드 플래너의 확정 수치가 아니라, 캡처에서 확인된 광고주 밀도와 현재 계정의 1,000원 입찰 설정을 바탕으로 한 **운영 테스트 권고값**이다.

| 키워드군 | 권장 시작 최대 CPC |
|---|---:|
| 외국인 마케팅 업체·대행사 | 2,500~4,000원 |
| 외국인 관광객 마케팅·유치 | 1,500~3,000원 |
| 외국인 인플루언서 섭외·마케팅 | 2,000~4,000원 |
| 외국인 체험단 | 1,200~2,500원 |
| 중국인·일본인 관광객 마케팅 | 1,500~3,000원 |
| 해외·글로벌 마케팅 대행사 | 3,000~6,000원 |

초기에는 일치검색과 구문검색 중심으로 운영하고, `채용`, `취업`, `알바`, `연봉`, `학과`, `자격증`, `강의`, `뜻`, `사례`, `무료`를 제외 키워드 후보로 둔다.

## 확인된 한계

- Google Ads 키워드 플래너의 예상 검색량·상단 입찰가 조회 권한이 현재 API 연결에 허용되지 않았다.
- 따라서 신규 후보 키워드의 검색량과 상단 입찰가를 Google 실측값으로 확정하지 않았다.
- 연결된 캠페인이 중지 상태이고 실제 집행 이력이 없어 키워드별 실제 CPC는 아직 없다.
