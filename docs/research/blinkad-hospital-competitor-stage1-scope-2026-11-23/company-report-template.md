사이트 내 칼럼과 외부 네이버 블로그/기고를 구분한다. 검색결과의 작성자 이름·브랜드 언급만으로 자사 계정이나 직접 작성 글로 집계하지 않는다. 유료 기사·자사 배포자료·계열사 콘텐츠는 독립된 권위 근거와 구분한다. 병원 마케팅 대행사의 경험/전문성을 우선 평가하고, 환자용 의료 내용이 있으면 의료 검수·출처를 별도 확인한다.

## 결론·검증

- 근거 상태: 공개자료 확인 / 자사 주장 / 교차 확인 / 해석·가설 / 미확인 / 해당 없음.
- 모든 핵심 수치·가격·계약 조건에 출처와 기준일을 연결한다. 상충하는 자료는 둘 다 기록한다.
- E-E-A-T 점수·순위 기여율을 임의 산출하지 않는다. 존재 여부와 구체성/검증 가능성을 사례로 비교한다.
- 검색광고 노출은 유기적 순위 원인으로 설명하지 않는다. 홈페이지와 다른 도메인의 글 순위도 분리한다.
- 자료 수집 완료 / 분석 완료 / 외부 확인 필요를 구분하고, 다음 조사 질문을 남긴다.
