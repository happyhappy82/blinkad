# 제안: 측정 조건과 월간 보고서 구성

2026-11-24. **측정을 실행하지 않은 검토 양식**이다. 새 모델/반복/플랫폼 수를 계약으로 확정하지 않았다. [현재 문서 차이](blinkad-baseline.json)와 [실행 우선순위](priority-backlog.json)를 함께 본다.

## 1. 측정 전 기록

플랫폼/공식 API 제공자·정확한 모델/버전·측정 경로(API/실제화면)·웹검색 발동/도구·언어/지역·질문 원문/버전/해시·질문 층위(브랜드/카테고리/선택상황)·반복 수·신규 대화/기억 조건·시각/시간대·목표 브랜드/별칭·공식 도메인·경쟁사 집계 규칙·예정/완료/유효/오류 수·원답변/인용 저장 위치를 기록한다.

사용자 지침상 신규 AI 언급률 실측은 공식 API가 기본이며 DataForSEO AI 계열은 쓰지 않는다. 특정 앱 UI를 측정한 값은 API와 합치지 않는다. Google AI 기능에 대한 공식 API 답변으로 실제 Google 검색 화면 노출률을 대체하지 않는다.

## 2. 분모와 실패를 공개한다

| 지표 | 계산/표시 | 해석 범위 |
|---|---|---|
| 실행 완결성 | 완료/예정 및 유효/완료, 오류 원인·재시도·제외 수 | 타임아웃/권한/쿼터 오류를 조용히 미언급으로 바꾸지 않음 |
| 브랜드 언급률 | 언급한 유효 응답/유효 응답, 분자·분모 모두 표시 | 언급이 추천·긍정 평가·매출이라는 뜻은 아님 |
| 자사 URL 인용률 | 공식 도메인 링크가 있는 유효 응답/유효 응답 | 이름만 나오는 경우와 구분 |
| 정보 정확도 | 검토한 사실 항목의 일치/불일치/판단 불가와 항목 수 | 근거 원문이 없는 항목을 자동 정답 처리하지 않음 |
| 질문별 반복 | 질문별 언급 횟수/유효 반복 수 | 일부 브랜드 질문이 전체 상승을 가리는지 확인 |
| 전후 변화 | 동일 조건의 분자/분모와 %포인트 변화 | 모델/경로/질문 변경 시 신규 기준선·별도 계열 |
| AI로 식별된 방문 | 분석 도구에서 식별 가능한 referrer/UTM 등 | 전체 AI 영향/노출 후 직접 방문까지 다 잡는 지표가 아님 |
| 문의 행동 | 버튼 클릭·폼 제출·실제 접수 각각 | 클릭은 접수/예약이 아님 |
| 실제 문의·예약 | 병원과 합의한 집계/연결 자료 범위 | 자료 미연결은 ‘미확인’. AI 언급 증가에 예약을 자동 귀속하지 않음 |

표시되지 않은 AI 브리핑을 포함하는 실 화면 측정과 API 오류 제외 기준도 따로 명세해야 한다. 업체 간 비율을 비교하려면 질문 구성·반복·유효성 정의부터 같아야 한다. 표본은 고정 질문 조건에서의 관측이며 전체 AI 시장 점유율이 아니다. 반복이 적으면 단월 출렁임만으로 우열/작업 효과를 확정하지 않는다.

## 3. 고객 보고서 순서

1. 이번 달 판단: 확인된 변화·아직 모르는 것·다음 우선 업무.
2. 합의한 납품: 신규/보강·언어·공개URL·검토/미발행·정보 변경/기술 수정.
3. 측정 조건·완료율: 모델/경로/질문버전/반복/검색/언어/지역·실패 수.
4. M00/전월/이번 달: 언급·공식 인용·질문별 반복과 사실 오류. 비교 불가한 계열은 별도 표.
5. 근거: 원답변ID·시각·인용URL·공개 원문 변경 기록. 표본을 고르는 기준도 명시.
6. 방문/문의: 도구가 확인한 행동과 병원 기록을 분리하고 미연결 범위 표시.
7. 다음 달: 관측→해석/가설→작업→확인 방법. 경쟁사 언급은 비방/성과 추정으로 쓰지 않음.

## 4. 사례 양식

공개 허가 범위 / 업종·지역·언어 / 기간 / 질문 구성 / 측정 방법·분모 / 실제 변경 / 동일 조건 전후 / 동시 광고·시즌·사이트 변경 / 병원 자료 연결 범위 / 성과 귀속 한계 / 원자료 위치.

현재 공식 사례 페이지에는 실제 프로젝트와 AI 성과 **표시 예시**가 이미 구분돼 있다. 예시 수치를 실제 고객 Before/After로 재사용하지 않는다. 승인된 실제 병원 자료가 없으면 작업 과정이나 양식만 제시한다. 새 환자별 정보 수집·공개를 이 보고서에서 요청하거나 실행하지 않는다.
