## 1. 약속할 결과와 관측할 반응

납품 약속은 합의한 질문·원고·페이지·프로필 변경·발행 주소·확인 자료·보고서다. 검색 순위, AI 추천, 광고 심의 승인, 실제 문의·예약·매출은 납품 수량과 구분한다. 관측할 지표와 병원 자료가 필요한 지표를 계약 전에 정한다.

## 3. 진단·구축·월 운영을 작업 범위로 나눈다

1. 진단: 현재 공개 정보·질문·사이트/프로필·문의 동선을 확인하고 수정 목록/담당/완료 자료를 정한다.
2. 구축이 필요할 때: 기존 사이트 수정, 다국어 페이지, 신규 사이트를 실제 접근·제작사 협조·범위에 맞춰 견적낸다. AEO 월액에 무조건 포함시키지 않는다.
3. 월 운영: 승인할 질문→자료 확인→원고/번역→병원 검토→합의된 반영→공개 결과 확인→조건 고정 재측정→다음 작업 결정.

이를3개 신규 유료 요금제로 만든다는 뜻은 아니다. 기존 계약의 제작비/반복 업무를 설명하는 구분이다. 특정 월에 성과가 난다는 일정 약속도 하지 않는다.

## 4. 병원과 대행사의 책임

병원은 실제 제공 진료·의료진·위치/시간·가격 적용 조건·상담 가능한 언어·자료 사용 허가와 최종 내용 확인자를 제공한다. 블링크애드는 합의한 조사/기획/작성/적용/확인 기록을 담당한다. 기존 제작사의 적용이 필요한 항목은 요청·반영 책임자를 정한다. 진료 적합성 판단·환자 상담·법률 판정을 마케팅 업무의 자동 포함 항목으로 쓰지 않는다.

## 5. 측정 정합성 결정

공개 AI 안내는 복수 플랫폼을 다루고, 설치된 월간 스킬은 Gemini Web60회 규칙이며 사용자 전역 지침은 신규 AI 실측을 공식 API로 하도록 한다. **새 실측에는 사용자 지침이 우선**한다. 이 보고서는 운영 스킬/계약/기존 결과를 바꾸지 않았다. 대상별로 어떤 서비스를 어떤 조건에서 볼지 정한 뒤 기준선을 만든다. API 응답을 ChatGPT 앱 화면과 같다고 설명하지 않는다. Google AI Overview/네이버 등 실제 화면 관측은 공식 API 응답과 별도 계열이며 이번에 새 관측을 실행하지 않았다.

## 7. 발주 전에 보여줄 최소 자료

- 합의한 범위/제외·추가 비용 표1장.
- 실제 결과를 쓰지 않은 **양식 예시** 또는 공개 허가된 자료: 납품URL/변경 기록/원답변 조건/월 보고.
- 병원 협조·내용 확인·반영 창구·종료 시 인계 목록.

현재 서비스의 존재를 새로 주장하거나 경쟁사보다 효과가 높다고 말하는 자료가 아니다. 동일 조건의 구매 비교를 돕는 명세다.
