## 중복 방지를 위해 제외한 주제

- 미용실 마케팅: 공개 글과 Notion Review 원고에 외국인 검색·문의·예약 주제가 이미 존재한다.
- 병원·피부과·성형외과·치과·한의원 마케팅: 공개 글과 미발행 원고가 다수 존재한다.
- 약국 마케팅: 공개 글 2개와 외국인 마케팅 Draft가 존재한다.
- 펜션 마케팅: 외국인 예약을 다루는 Review 원고가 존재한다.
- 외식업 마케팅 종합편: 식당·카페 글과 검색 의도가 겹칠 가능성이 있어 별도 원고로 만들지 않았다.

## 공통 SEO·AEO·GEO 구조

각 원고에는 다음 요소를 반영했다.

- 제목과 H1에 주 키워드 1회 포함
- 첫 문단에서 고객 질문에 직접 답변
- 하나의 독자 상황과 하나의 주 검색 의도
- 질문형 H2와 비교 표 또는 실행 순서
- 블링크애드가 실제 진단에서 확인하는 절차를 경험 근거로 공개
- 확인되지 않은 성과 수치, 가상 고객 후기와 순위 보장 배제
- 정확히 3개의 FAQ
- Google·한국관광공사·플랫폼 공식 자료 중심의 참고 자료
- 고유 제목, Slug, Excerpt와 최종 검수일

## 내부·외부 링크 원칙

- 외부 링크는 Google, 한국관광공사, 아고다, 트립닷컴 등 해당 사실을 직접 설명하는 공식 문서로 연결했다.
- 공식 근거는 참고 자료 목록에만 두지 않고, 검증이 필요한 주장 바로 옆에 문맥형 링크로 배치했다.
- 내부 링크는 블링크애드의 외국인 마케팅·Google 지도 마케팅 서비스와 독자의 다음 질문에 답하는 기존 공개 글로 연결했다.
- 시리즈 내부 링크는 앞 순서 원고만 가리킨다. 1번부터 순서대로 발행하고, 앞 글의 공개 URL이 정상 작동하는 것을 확인한 뒤 다음 글을 올린다.
- 발행 전 URL이 바뀌면 시리즈 링크와 이 문서의 발행 순서를 함께 수정한다.

## 2026-09-03 재검토 결과

- 사이트 코드의 공개 블로그 95편과 제목을 비교했으며 동일 제목은 없었다.
- 공개 글 본문과 45자 이상 문장을 정규화해 비교했으며 그대로 겹치는 문장은 없었다.
- 12편 모두 제목과 H1에 주 키워드가 포함되고, 질문형 H2와 FAQ 3개, 실제 점검 절차를 설명하는 경험 섹션이 있다.
- 글별 내부 링크는 3~5개, 본문 안 공식 외부 근거 링크는 3~6개다.
- 고유 URL 43개를 검사한 결과 기존 블링크애드·Google·한국관광공사·트립닷컴 링크 35개는 HTTP 200이었다.
- 아고다 파트너 허브 3개는 자동 검사 요청에 HTTP 403을 반환했지만 공식 검색 결과에서 동일 URL과 최신 본문을 확인했다. 삭제된 링크가 아니라 자동화 접근 제한으로 분류했다.
- 시리즈 원고 URL 5개는 아직 미발행이라 HTTP 404가 정상이다. 모두 앞 순서 글만 가리키므로 순차 발행 후 바로 재검사한다.

블링크애드 사이트의 현재 블로그 상세 페이지는 `Article`과 `BreadcrumbList` 구조화 데이터를 생성한다. 발행 시 제목, Excerpt, 작성자, 대표 이미지, 게시일과 수정일이 실제 화면과 구조화 데이터에서 일치하는지 확인한다.

FAQ는 독자가 질문별 답을 찾고 검색·AI 시스템이 문맥을 이해하기 쉽게 하기 위한 본문 구조다. 일반 마케팅 블로그가 FAQ 리치 결과에 노출된다고 보장하지 않으며, 지원 자격을 확인하지 않은 `FAQPage` 마크업은 추가하지 않는다.

## 발행 전 최종 확인

1. 기존 Published·Review·Draft에 동일한 검색 의도의 원고가 새로 생기지 않았는지 다시 검색한다.
2. 플랫폼 기능, 운영시간, 가격과 정책처럼 변할 수 있는 사실을 발행일 기준으로 재확인한다.
3. 업종별 실제 사례를 추가한다면 고객명, 화면, 수치와 사용 권한을 확인한다.
4. 본문에서 연결한 공식 출처와 내부 링크가 정상적으로 열리는지 확인한다. 아직 미발행인 시리즈 URL은 앞 순서 글 발행 직후 다시 검사한다.
5. 12개 글을 한꺼번에 발행하지 말고, 각 글의 품질과 검색 반응을 확인할 수 있도록 순차 발행한다.
